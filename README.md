# Chalanger

Личный альбом идей для рисования. Записи, их порядок и оформление хранятся в IndexedDB. Service worker сохраняет файлы приложения для работы без интернета после первого запуска.

## Локальный запуск

Требуется Node.js 24. Установите зависимости (`npm ci`) и запустите `npm run dev`.
`npm run build` создаёт каталог `dist`; `npm run preview` показывает готовую сборку. Service worker работает в production-сборке на localhost и HTTPS.

## Android

`npm run android:sync` собирает интерфейс и синхронизирует Android-проект. Затем откройте `android` в Android Studio или выполните `gradlew assembleDebug` из этого каталога.
Подробности: [Android и подпись](docs/ANDROID.md), [подготовка RuStore](docs/RUSTORE.md).

В первой Android-версии добавлены поиск, избранное, даты, системный импорт/экспорт, «Поделиться» и добровольные локальные напоминания. Подборки «Маленькая жизнь» и «Школа фей» используют оригинальные задания.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **GitHub Actions** в поле **Source**. Каждый push в `main` запускает сборку и публикацию каталога `dist`. Ключ офлайн-кэша строится из содержимого итоговых файлов. Готовое обновление предлагается кнопкой в приложении.

Пользовательские данные сохраняются при обновлениях на том же адресе. В «Палитре» можно экспортировать и восстановить копию альбома в формате JSON. Восстановление заменяет текущий альбом после подтверждения.

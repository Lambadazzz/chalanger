# Chalanger

Личный альбом идей для рисования. Записи, их порядок и оформление хранятся в IndexedDB. Service worker сохраняет файлы приложения для работы без интернета после первого запуска.

## Локальный запуск

Запустите HTTP-сервер из каталога `web` и откройте его адрес на `localhost`. Service worker доступен на localhost и HTTPS.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **GitHub Actions** в поле **Source**. После этого каждый push в `main` запускает публикацию каталога `web`. Для каждой сборки workflow меняет ключ офлайн-кэша на SHA коммита. Готовое обновление предлагается кнопкой в приложении.

Пользовательские данные сохраняются при обновлениях на том же адресе. В «Палитре» можно экспортировать и восстановить копию альбома в формате JSON. Восстановление заменяет текущий альбом после подтверждения.

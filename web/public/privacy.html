Политика конфиденциальности Чаланжера

Редакция от 8 ноября 2026 года. Разработчик: Руслан Н. Контакт: nyshev00@gmail.com.

Данные альбома

Чаланжер — бесплатный личный альбом идей для рисования. Тексты карточек, оформление, отметки избранного, состояние выполнения и даты хранятся в локальном хранилище устройства. Выбор времени напоминания хранится локально в Android-приложении. Эти сведения нужны для работы альбома и напоминаний.

В приложении нет аккаунтов, рекламы, аналитики или сервера синхронизации. Альбом не отправляется разработчику. Android-версия работает без разрешения на доступ в интернет. Сведения сохраняются до удаления пользователем или очистки хранилища; карточки можно удалить в приложении, все данные — через настройки Android или очистку данных сайта в браузере.

Файлы и другие приложения

Резервная копия создаётся только по запросу пользователя. Файл содержит карточки и оформление альбома. Пользователь сам выбирает место сохранения и файл для восстановления. Если выбран облачный провайдер документов, он обрабатывает файл по своим условиям. Экспортированные копии не удаляются при удалении приложения и удаляются пользователем отдельно.

При нажатии «Поделиться» текст передаётся выбранному пользователем приложению или копируется в буфер обмена в браузере. Дальнейшая обработка регулируется условиями выбранного сервиса. Автоматическое облачное резервирование данных Android-приложения отключено.

Разрешения

Разрешение на уведомления запрашивается только при включении напоминания. Можно отказаться или отозвать его в настройках Android: альбом продолжит работать. Служебные разрешения восстановления после перезагрузки и удержания устройства нужны механизму локальных уведомлений. Чаланжер не запрашивает доступ к контактам, геолокации, камере или ко всем файлам устройства.

Обращения в поддержку

При отправке письма разработчик получает адрес отправителя, содержание и добровольно приложенные сведения для ответа на обращение. Почтовый сервис Gmail обрабатывает переписку по своим условиям. Не отправляйте пароли и чувствительные сведения; прикладывайте резервную копию только при необходимости. Запрос о доступе к переписке или её удалении можно направить по адресу поддержки.

Порядок и срок хранения обращений требуют утверждения разработчиком перед публичным выпуском. Эта редакция документа подготовлена для проверки, а не для отправки в магазин без проверки.
